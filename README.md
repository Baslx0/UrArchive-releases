# UrArchive Releases

This repo hosts compiled desktop installers for **UrArchive** — a private, local-first Snapchat Memories Explorer.

Source code lives in a separate private repository. This repo intentionally contains no source, only built binaries attached to [Releases](https://github.com/Baslx0/UrArchive-releases/releases).

## Download

Grab the latest installer from the [Releases page](https://github.com/Baslx0/UrArchive-releases/releases/latest).
